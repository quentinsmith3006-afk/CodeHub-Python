## How is Python Useful?
Python is a Object Oriented Language. Everything in Python is a object! A Object Oriented Programming language conforms to standardized OOP principles of inhieritance, polymorphism, encapsulation and abstraction. Lots of languages use OOP and OOP practices are standard in the Computer Science industry.

Python is also a high level language. All this *really* means is that Python is easier to read!
```
for x in range(5):
    print(x)
```
This for-loop prints the numbers 0-4. I am sure that you could atleast partially guess what it does. 

Additionally, Python uses an interpreter to read and run a Python file. In the terminal,  "python3" in the command below is calling the interpreter to run the file. 

`python3 filename.py`
